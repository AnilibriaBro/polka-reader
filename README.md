# Полка — офлайн-читалка книг

Мобильное приложение для чтения книг на телефоне, которое работает полностью без интернета:
книги и данные хранятся в памяти телефона в базе SQLite. Бесплатно, без рекламы, без регистрации
и без сбора личных данных.

- **Android:** [скачать Polka.apk](https://github.com/AnilibriaBro/polka-reader/releases/latest/download/Polka.apk)
- **iPhone:** открыть в Safari https://anilibriabro.github.io/polka-reader/ → «Поделиться» → «На экран „Домой“»

Как установить — в [УСТАНОВКА.md](УСТАНОВКА.md).

## Какие проблемы читалок решает

| Проблема обычных читалок | Как в «Полке» |
|---|---|
| Реклама, платная подписка | Нет ни того, ни другого |
| Регистрация, сбор данных | Аккаунтов нет, всё хранится только на телефоне |
| Нужен интернет | Читать можно без сети; интернет нужен только для поиска новых книг |
| «Кракозябры» в старых русских TXT | Кодировка определяется сама (UTF-8, Windows-1251, KOI8-R, DOS-866) |
| Теряется место, где остановился | Позиция сохраняется после каждой страницы и не сбивается при смене шрифта |

## Возможности

- Книги **EPUB, FB2, TXT, HTML** и архивы **ZIP** с ними; обложка, автор и оглавление берутся из файла.
- На Android книгу можно открыть прямо из Telegram или «Файлов»: «Открыть с помощью → Полка».
- **Найти книгу**: бесплатная классика, у которой закончились авторские права, — русская
  ([Викитека](https://ru.wikisource.org)) и мировая ([Project Gutenberg](https://www.gutenberg.org)).
- Чтение постранично: тап по краю или свайп — листать, тап посередине — меню.
- Закладки, оглавление, ползунок «место в книге», прогресс в процентах.
- Размер шрифта, шрифт с засечками или без, темы: светлая, сепия, тёмная.
- Русские переносы по слогам — без дыр между словами при выравнивании по ширине.

## Как устроено

- **React + TypeScript + Vite**; Android-приложение — через **Capacitor**, для iPhone — веб-версия (PWA), которая работает без интернета.
- **SQLite** (sql.js, WebAssembly). Две базы: тексты книг и всё остальное (книги, позиции, закладки, настройки),
  чтобы сохранение позиции было мгновенным.
- Книга хранится кусками (по главам, до ~30 тыс. символов) — большие книги открываются быстро.
- Страницы — CSS-колонки шириной в экран; позиция хранится номером символа, поэтому после смены шрифта
  или поворота экрана открывается то же место.

| Файл | Что в нём |
|---|---|
| `src/db.ts` | база SQLite: книги, позиции, закладки, настройки |
| `src/importer.ts` | чтение TXT и FB2, кодировки, деление на главы |
| `src/epub.ts`, `src/zip.ts`, `src/html.ts` | чтение EPUB и ZIP, текст из HTML |
| `src/hyphen.ts` | русские переносы |
| `src/Library.tsx`, `src/Reader.tsx`, `src/Find.tsx` | экраны: полка, чтение, поиск книг |
| `src/wikisource.ts`, `src/gutenberg.ts` | поиск и скачивание из библиотек |
| `src/openWith.ts` | приём книг из других приложений на Android |

## Безопасность

- Приложение обращается в интернет только к двум библиотекам — это задано правилом страницы (Content Security Policy).
- У Android-приложения одно разрешение — интернет; доступа к памяти, контактам и камере нет.
- Текст книги показывается только как текст: скрипты и ссылки внутри файлов книг не выполняются.
- ZIP распаковывается с ограничениями размера, чтобы испорченный архив не повесил телефон.

## Сборка

```
npm install
npm run dev                  # проверка в браузере
npm run build                # веб-версия в dist/
.\build-apk.ps1              # APK для Android (нужны Java 21, Android SDK и ключ подписи)
```

Ключ подписи в репозиторий не входит: путь к файлу с ним указывается в `android/local.properties`
строкой `polka.keystore=...`.
