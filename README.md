# «Полка» — читалка книг для телефона

**Статус:** готово (APK собран и проверен в браузере); веб-версия для iPhone собрана, но ещё не выложена — ждём команды хозяина
**Начата:** 2026-10-30

## Что просили

Проект брата хозяина для школы, срок — сегодня-завтра. Требований от учителя нет, текст для защиты не нужен.
Задание брата (его промт):

> мобильное приложение для чтения книг на телефоне, которое решает проблемы существующих читалок.
> Работает полностью офлайн: все книги и данные пользователя хранятся в памяти телефона в базе данных
> SQLite. Добавлять книги из текстовых файлов, читать, ставить закладки, менять размер шрифта,
> переключать тему (светлая / тёмная). Автоматически сохранять позицию чтения и восстанавливать её
> при следующем запуске, показывать прогресс в процентах. Бесплатно, без рекламы и без сбора данных.

Хозяин согласился с правками: добавить FB2, автоопределение кодировки, быстрое открытие больших книг;
iPhone — как у «Олимпиад» (веб-версия + иконка на экран «Домой»). Комментарии в коде — от лица хозяина
(сначала по-русски, потом по-английски), коммиты без подписи Claude.

**Сессия:** «читалка для брата» (запущена из «петпроекты Китай» `local_13770a5a-c471-4b9f-8c5d-ec208200d955`)

## Где что лежит

| Что | Где |
|---|---|
| Готовый APK для Android | `проекты\polka-reader\Polka.apk` |
| Код приложения | `src\` (описание ниже) |
| Книга-пример «Капитанская дочка» (Пушкин, общественное достояние) | `public\sample\kapitanskaya-dochka.fb2` |
| Профиль для iPhone (иконка на экран «Домой») | `public\Polka-iPhone.mobileconfig` |
| Скрипты: иконки, профиль iPhone, книга-пример | `scripts\` |

Файлы кода:
- `src\db.ts` — база SQLite (две базы: тексты книг и всё остальное), сохранение в память телефона;
- `src\importer.ts` — чтение TXT и FB2, определение кодировки, разбивка на главы;
- `src\hyphen.ts` — русские переносы по слогам;
- `src\Library.tsx` — экран «Полка»; `src\Reader.tsx` — экран чтения; `src\Cover.tsx` — обложки;
- `src\index.css` — оформление и темы.

## Что умеет

- Добавление книг **TXT и FB2** (несколько файлов сразу), пример книги одной кнопкой.
- **Автоопределение кодировки**: UTF-8, Windows-1251, KOI8-R, DOS-866 (старые русские TXT не превращаются в «кракозябры»).
- В TXT сам находит главы («Глава…», «Часть…», римские цифры) и способ разбивки абзацев (отступы / пустые строки / строки).
- Из FB2 берёт название, автора, обложку, главы, эпиграфы, стихи.
- Чтение **постранично**: тап по краю или свайп — листать, тап посередине — меню.
- **Закладки** (красная ленточка на странице), список закладок с цитатой, удаление.
- **Оглавление** с процентами, ползунок «место в книге».
- **Шрифт**: размер 14–30, с засечками (Literata, сделан для чтения с экрана) или без (Onest); выравнивание по ширине.
- **Темы**: светлая, сепия, тёмная.
- **Позиция** сохраняется после каждой страницы и открывается при следующем запуске; прогресс в процентах на полке и внизу страницы.
- Удаление книги (с подтверждением). Кнопка «Назад» на Android работает как ожидается.
- Без интернета, рекламы, регистрации, сбора данных (политика безопасности страницы запрещает любые запросы наружу).

## Ключевые решения

- **React + Capacitor**, как «Олимпиады»: один код для Android (APK) и iPhone (веб-версия). Сборка уже настроена у нас.
- **SQLite через sql.js** (SQLite, скомпилированный в WebAssembly), файл базы хранится в IndexedDB.
  Почему не нативный плагин: один и тот же код работает и в APK, и на iPhone, без лишних плагинов.
- **Две базы**: `library.sqlite` (тексты) и `reader.sqlite` (книги, позиции, закладки, настройки).
  Позиция сохраняется после каждой страницы — так не приходится переписывать мегабайты текста.
- **Книга режется на куски** (по главам, но не больше ~30 тыс. символов). На экране только один кусок →
  большие книги открываются мгновенно.
- **Страницы — CSS-колонки** шириной в экран; листание = сдвиг. Позиция хранится как номер символа,
  поэтому после смены шрифта или поворота экрана остаётся то же место.
- **Свои переносы** (`hyphen.ts`): браузер на Windows и некоторых телефонах русских переносов не знает,
  без них при выравнивании по ширине были огромные дыры между словами.
- **Обложка без картинки** рисуется «под старый тканевый переплёт» с золотым тиснением — цвет зависит от названия.
- APK подписан **тем же ключом, что «Олимпиады»** (`Документы\olympiads-keys`), id приложения `ru.polka.reader`.

## Что изучено / находки

- `\b` в регулярных выражениях JavaScript не работает с русскими буквами — заголовки «Глава» в TXT не находились. Заменил на проверку вручную.
- На az.lib.ru нет готовых FB2 (ссылка `.fb2` даёт 404) — пример сделан из HTML-страницы скриптом `scripts\make_sample.py`.
  После 14-й главы на странице идут «Пропущенная глава» и черновики с комментариями — в пример не включены.
- PowerShell 5.1 читает `.ps1` без BOM как ANSI — русские строки ломают скрипт. `build-apk.ps1` сохранён с BOM.
- Проверено в браузере (ширина телефона и компьютера): добавление TXT в Windows-1251 и KOI8-R, FB2 с обложкой,
  ошибка на неподдерживаемом файле, листание тапом/свайпом/клавишами, закладка, оглавление, ползунок, темы,
  размер шрифта, сохранение места после перезагрузки и после изменения размера окна, удаление книги.

## Как собрать

```
npm install
npm run dev                       # проверка в браузере, http://localhost:5181 (или preview «polka-dev»)
.\build-apk.ps1                   # подписанный Polka.apk
python scripts/make_icons.py      # иконки (веб + Android)
python scripts/make_ios_profile.py
```
