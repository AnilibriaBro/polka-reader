# Как поставить «Полку» на телефон

## Android

1. Скачай файл по ссылке прямо на телефоне: https://github.com/AnilibriaBro/polka-reader/releases/latest/download/Polka.apk
   (или перекинь себе файл `Polka.apk` в Telegram «Избранное»).
2. Открой скачанный файл → «Установить». Если телефон спросит про «неизвестные источники» —
   разреши установку для браузера или Telegram (того приложения, откуда открываешь файл).
3. Готово: на экране появится иконка «Полка» (зелёная книга с красной ленточкой).

Книги из Telegram открываются сразу в «Полке»: нажми на файл книги → «Открыть с помощью» → «Полка».

## iPhone

1. Открой в **Safari** (именно в Safari, не в Telegram): https://anilibriabro.github.io/polka-reader/
2. Нажми кнопку «Поделиться» (квадрат со стрелкой вверх) → «На экран „Домой“» → «Добавить».
3. Открывай «Полку» с иконки на экране — так она работает как приложение и без интернета.

Книгу, скачанную отдельно, добавляй так: «Добавить книгу» → «Выбрать файл» → выбери файл в «Файлах».

## Что умеет

- Читает EPUB, FB2, TXT и архивы ZIP с ними.
- «Найти книгу»: бесплатная классика — русская (Викитека) и мировая (Project Gutenberg).
- Тап по краю страницы или свайп — листать, тап посередине — меню: закладка (ленточка), оглавление,
  шрифт, тема (светлая, сепия, тёмная).
- Само запоминает, где остановился. Без рекламы, без регистрации, книги хранятся только на телефоне.
